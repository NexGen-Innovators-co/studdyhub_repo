# StuddyHub v1.0-beta.1 — Explorer Tier Beta Release

> **First public beta release** focusing on the Explorer tier (Basic & JHS students in Ghana).

---

## What's New

### AI Tutor — Ollie the Wise Owl
- **AI Chat** with Ollie, a friendly AI study buddy powered by Gemini
- Age-appropriate responses for students under 13
- Ghanaian cultural examples (Kwaku Ananse, Oware, Kenkey, football)
- Child safety guard blocks personal information sharing

### Live Multiplayer Battles
- **1v1 Battle Arena** — compete against other students in real-time quizzes
- **Speed Race** — fast-paced solo quiz challenge
- Create private rooms or join with a Game PIN
- Live leaderboard with streak multipliers

### Games & Learning
- **Oware Beads** — learn addition and subtraction through the traditional Oware game
- **Spelling Bee** — practice spelling with voice input
- **Math Asteroid Blaster** — solve math problems to save the planet
- **Word Crush** — match letters to form words

### Study Tools
- **Interactive Lessons** — step-by-step explanations with stories and examples
- **AI-Generated Quizzes** — Ollie creates quiz questions on any topic
- **Flashcards** — create and study flashcard decks
- **Explorer Roadmap** — a quest-style learning path with milestones

### Progress Tracking
- **Streak Calendar** — track your daily study streak
- **XP & Leveling** — earn experience points for completing activities
- **Badges** — unlock achievements for milestones
- **Dashboard** — overview of your progress, notes, and schedule

## System Requirements

| Requirement | Minimum |
|-------------|---------|
| Android Version | 8.0 (API 26) |
| RAM | 2 GB |
| Storage | 100 MB free |
| Internet | Required for AI features, offline fallback available for quizzes |

---

## Installation

1. Download the `app-release.apk` file below
2. Transfer to your Android device (or download directly on the device)
3. Open the APK file
4. If prompted, enable **"Install from unknown sources"** in your settings
5. Open StuddyHub and sign up
6. Select **"Explorer"** tier during onboarding
